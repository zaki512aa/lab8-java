## Подготовка базы данных
База данных разворачивается автоматически в оперативной памяти при запуске программы:
1. Создаётся схема `study` (`CREATE SCHEMA IF NOT EXISTS study`).
2. Выполняется скрипт `src/main/resources/music-create.sql` для создания и наполнения таблицы `study.music`.
3. Таблицы `visitors`, `books` и `visitor_books` создаются программно и заполняются уникальными записями из `src/main/resources/books.json`.
